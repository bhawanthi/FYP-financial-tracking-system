## 🚀 Quick Start (Everyone)

### For Users (5 minutes)
```
1. Open: http://localhost:3000/investment-planner
2. Enter: Amount (Rs 10,000), Currency (LKR), Duration (3m), Company (Commercial Bank)
3. Click: "Calculate Return"
4. View: Results showing interest earned
5. Export: PDF if needed
```

### For Developers (10 minutes)
```bash
# 1. Verify backend running
curl http://localhost:5000/api/investments/companies

# 2. Verify frontend loads
Visit http://localhost:3000/investment-planner

# 3. Test calculation
Enter 10,000 → Click Calculate → Should show Rs 250 interest

# 4. Review code
- Component: frontend/src/components/InvestmentCapitalPlanner.js
- Service: BACKEND/services/investmentPlannerService.js
- API: BACKEND/routes/investments.js
```
