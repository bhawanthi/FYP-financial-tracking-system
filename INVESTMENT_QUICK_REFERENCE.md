## 📊 Formulas at a Glance

### Simple Interest
```
SI = Amount × Rate × Time
Result = Amount + SI

Example: Rs 10,000 × 10% × 0.25 years = Rs 250 interest
         Total = Rs 10,250
```

### Compound Interest
```
CI = Amount × (1 + Rate)^Time - Amount
Result = Amount + CI

Example: Rs 10,000 × (1.10)^0.25 = Rs 10,240.06
         Interest = Rs 240.06
         Total = Rs 10,240.06
```

## 💡 Tips & Tricks

### Tip 1: Compound vs Simple
```
Compound Interest ALWAYS ≥ Simple Interest
Difference increases with:
✓ Longer duration (3m → 6m → 1 year)
✓ Higher interest rates (5% → 10%)

Example difference: 
- 3 months @ 10%: +Rs 2.50 extra
- 1 year @ 10%: +Rs 100 extra
```

### Tip 2: Currency Switching
```
1. Select currency FIRST
2. Enter amount in that currency
3. All calculations update automatically
4. Export in selected currency

🔄 Switch anytime - calculations recalculate instantly
```

### Tip 3: Compare Different Options
```
Don't settle for first choice!

Instead:
1. Calculate Option A
2. Note the interest
3. Reset form
4. Calculate Option B
5. Compare both

→ Compound Stock ETF (11%) vs Commercial Bank (10%)
→ Over 1 year: Rs 1,100 vs Rs 1,000 = Rs 100 difference!
```

Each company has a minimum:

## 🔧 Advanced Features

### Manual Formula Calculation
```
If you want to verify calculations:

Simple Interest:
SI = 10,000 × (10/100) × 0.25 = 250

Compound Interest (Monthly):

```

### Currency Conversion Formula
```
To convert between currencies:
Amount_B = Amount_A × (Rate_B / Rate_A)

Example: Convert Rs 10,000 to USD
USD = 10,000 × (1 / 303.5) = $32.97
```
